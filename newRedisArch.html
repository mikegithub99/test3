Design principleCoordinate scans for efficiency. Enforce correctness at each server resource.

03 Summaries · safety facts

summary:server:{type}:{id}

Per-server counters + metadata

summary:type:{type}

Aggregated counters + type metadata

ACTIVE → DELETING One atomic fence wins against heartbeat refresh.

All job/lifecycle writers reject a fenced server. Cleanup validates and updates counters atomically; repeat calls detect already-completed cleanup.

Identity rule: DELETING is terminal; server IDs are not reused.
